# Политика конфиденциальности FREE PDF

FREE PDF обрабатывает выбранные фотографии, сканы и документы на iPhone. Приложение не требует регистрации, не содержит рекламы и аналитики и не передаёт файлы разработчику.

Камера используется для сканирования документов по запросу пользователя. Приложение получает только фотографии и файлы, которые пользователь выбрал для обработки. Готовый PDF временно хранится на устройстве. При сохранении или отправке пользователь сам выбирает папку или приложение, которому передаётся файл.

Вопросы о конфиденциальности можно задать через [страницу поддержки](README.md).
