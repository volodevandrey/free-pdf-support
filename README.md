# Поддержка FREE PDF

**Как собрать PDF.** Добавьте страницы с камеры, из «Фото» или «Файлов». При необходимости измените порядок или поверните страницы. Выберите лимит 2, 5 или 10 МБ и нажмите «Собрать PDF».

**Что делать, если файл слишком большой.** Уберите лишние страницы, разделите документ на несколько файлов или выберите больший лимит, если его принимает сайт. Перед отправкой откройте «Проверить читаемость».

**Как сохранить файл.** Нажмите «Сохранить или отправить», затем выберите «Сохранить в Файлы» или приложение, через которое хотите отправить PDF.

**Почему не открывается исходный PDF.** Проверьте, открывается ли он в «Файлах». Если документ защищён паролем, используйте доступную вам копию без пароля.

При обращении в поддержку укажите модель iPhone, версию iOS и шаги, на которых возникает ошибка. Удалите личные данные со скриншота перед отправкой.
